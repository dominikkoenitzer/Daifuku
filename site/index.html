Daifuku

Daifuku opens a grid of AI agent terminals with one key and colours each window's border by what its agent is doing.

Download for Windows

For Windows 10 and 11 with Windows Terminal, on an account that is an administrator. On an ARM PC, take the ARM64 version. Both also come as a zip: x64, ARM64.

If Windows says it protected your PC, click More info, then Run anyway.

Daifuku runs on Windows. Open this page on your PC to download it.

Next

One key to the waiting agent

Ctrl+Alt+N brings up the agent that has waited longest, then the failed ones. Press it again for the next one.

Yellow means waiting, red failed, blue working and green done.

Setup

Double-click to install

Double-click daifuku.exe, press Enter and allow it. It copies itself to Program Files, lists itself in Settings, Apps and starts at every sign-in.

daifuku doctor checks the whole setup and says how to fix anything that is off.

Scripts

Every command speaks JSON

Add --json and a command prints one JSON document, errors included. A script or an assistant reads each agent's state from daifuku status --json.

Colours

Readable to every eye

Every state has its own border width, so the states read without colour. A colour-blind palette is one line in the config.

Config

Every key is optional

The defaults work without editing. daifuku config opens the file, and the daemon picks up every saved change within two seconds.

Set how many terminals a fleet opens, on which monitor, in which folder and with which key. daifuku config validate checks the file the way the daemon reads it.

C:\ProgramData\Daifuku\daifuku.json

{
  "fleets": [
    { "name": "agents", "count": 6, "monitor": "portrait" },
    {
      "name": "site",
      "count": 4,
      "monitor": "primary",
      "directory": "C:\\src\\site",
      "hotkey": "ctrl + alt + w"
    }
  ]
}

Details

Version 0.2.0

What's new

  • A fleet can fill half its monitor, or any part of it, with the area key.
  • The with key opens a second fleet together with the first.
  • daifuku spawn opens a single agent terminal, and daifuku restore brings those back after Windows restarts.
  • daifuku wait waits until an agent finishes its turn.
  • The priority key runs a fleet's agents at a lower priority, and nothing they start outlives the terminal.
Requirements

What you need

  • Windows 10 or 11, x64 or ARM64
  • Windows Terminal
  • An account that is an administrator itself
  • About 4 MB to download
  • No internet connection
Privacy

Nothing goes online

Daifuku has no network access, no telemetry and no update check. Agents report their state over a local pipe on your PC.

Your data

One folder for config and logs

The config, the saved state and a log a day live in C:\ProgramData\Daifuku. The program itself is in C:\Program Files\Daifuku.

Keyboard

Global keys, all of them changeable in the config.

  • Open the fleet in its gridCtrl+Alt+Enter
  • Go to the agent waiting longestCtrl+Alt+N
  • Put every terminal back in its cellCtrl+Alt+Backspace
  • Close every fleet at onceCtrl+Alt+F4

Install, update and remove

01

Get started

  1. Download daifuku.exe.
  2. Double-click it, press Enter and allow it.
  3. Press Ctrl+Alt+Enter to open your first fleet.
02

Updates

Download the new daifuku.exe and double-click it again. Your config and hooks are kept.

03

Removing it

Settings, Apps, Installed apps, the three dots next to Daifuku, Uninstall. Config and logs stay; daifuku uninstall --purge from an administrator terminal removes those too.

Questions

Is Daifuku free?

Yes. It is open source under the GPL-3.0 licence.

Why does Windows say it protected my PC?

Daifuku is not signed with a paid certificate, so Windows warns about it the first time. Click More info, then Run anyway.

Can I try it without an agent?

Yes. daifuku demo from an administrator terminal opens six scripted agents.

Why does it need administrator rights?

The daemon runs as administrator so that no ordinary program can change what it starts, and fleets open as administrator by default. "admin": false on a fleet opens its terminals as you.

Where does my data live?

In C:\ProgramData\Daifuku: the config, the saved state and the logs. Nothing leaves your PC.
